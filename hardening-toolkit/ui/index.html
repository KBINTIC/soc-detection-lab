Console de durcissement du poste

Bahiri Consultant IT · MSP Cybersécurité

Séquence d'audit et de durcissement d'un poste Windows, dans l'ordre : on prouve d'abord que la détection fonctionne, on photographie l'état initial, on corrige avec validation humaine, puis on compare avant / après. Chaque script est en PowerShell, lancé dans un terminal administrateur.

🛡️ Principe : la machine exécute, l'humain décide. Rien n'est corrigé sans votre accord, et chaque correction est réversible.
